# 首页与内容入口

- Scope: 首页、文章入口、项目入口；主页为 Experience，列表与详情为 Read。
- Audience/job: 访客快速确认站点包含写作与项目，并选择任一路径继续探索。具体职业受众尚未确认。
- Primary actions: “阅读文章”和“浏览项目”同等可见；文章与项目在首页同权。
- Content truth: 不展示未经确认的履历、头像、客户或成果；模板内容仅在开发环境作为草稿预览。
- Direction: 继承 Zaggonaut 的黑白复古像素世界、硬边框、点阵和单一绿色强调色；正文切换为中文长读字体。
- Memorable moment: 首页像素 JP 模块与双路径声明把写作和项目合成一个作者索引。
- Constraints: 中文默认、移动优先、键盘可用、静态构建、无 JavaScript 时核心内容仍可阅读。
- Open decisions: 正式域名、真实简介、头像、社交账号、长期主题与双语计划。
